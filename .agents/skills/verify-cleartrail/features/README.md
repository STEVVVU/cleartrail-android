Run 41417601001 reached destination selection but failed because ATD had no CREATE_DOCUMENT activity. Export and the separate compiled Room migration/reopen and production-repository process-restart tests remain unaccepted. The UI journey does not exercise replacement from Saved or Room persistence through the UI. |
